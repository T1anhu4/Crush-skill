# 安全与可靠性增量 · 2026-09-21

本轮优先修复可复现的问题，不新增角色或改动私人会话。基线 133 项 Python 测试通过，但新增的边界测试仍发现缺陷：已有测试通过不代表安全和体验完善。

## 已修复的安全发现

### S1 · High · 模型请求自动跟随重定向

- 规则：FASTAPI-SSRF-001（出站请求的重定向控制）。
- 位置：`crush_core/provider.py:15`、`crush_cli/app.py:22`、`Crush.skill/engines/dialogue_analyzer.py:27`。
- 证据：原来直接使用标准 `urlopen`；本地模拟 302 从 `127.0.0.1` 跳转至 `localhost`，目标确实收到合成 Bearer 凭据。CLI 的三种协议入口及 Skill 分析也会继续请求重定向目标。
- 影响：在配置的服务返回跨地址重定向时，凭据可能被带往非用户指定的目标。不是任意网页都能触发，也没有证据表明真实密钥已经泄露。
- 修复：关闭自动重定向；v3/CLI 提示填写最终 API 地址，旧 Skill 分析保留原有本地分析回退。正常直接连接本地模型的测试仍通过。
- 兼容性：依赖 301/302 自动跳转的 API 配置需要改为最终地址。这不是模型服务可信性保证；用户仍须自行选择可信服务。

### S2 · Low · 请求体大小限制可绕过

- 规则：FASTAPI-LIMITS-001。
- 位置：`crush_core/server.py:27`。
- 证据：原先只判断 `Content-Length`；无长度头或伪造小长度的测试请求均能创建会话。
- 影响：持有本地请求令牌的客户端可使接口解析超出限制的 JSON；本机部署降低了远程暴露程度，不将此描述为公网未授权攻击。
- 修复：鉴权后、JSON 解析前累计实际接收字节，超过 64 KiB 立即返回 413，不继续读取剩余分块，也不执行路由。请求头仍用于快速拒绝。
- 边界：不等于速率限制、慢连接防护或公网部署认证；不要把本地服务转发至公网。

### S3 · Medium · 校验错误回显输入密钥

- 规则：FASTAPI-RESP-001。
- 位置：`crush_core/server.py:195`。
- 证据：超长 API Key 触发 422，默认校验响应含原始 `input`，回显完整合成密钥。
- 影响：密钥被多复制到错误响应，增加浏览器调试、日志或故障截图中的暴露面；不是其他用户可直接读到已保存密钥。
- 修复：只返回白名单字段的中文提示，不返回原始输入、异常上下文或原始错误文本。

### S4 · Low · 畸形 Host 导致未处理异常

- 规则：FASTAPI-HOST-001。
- 位置：`crush_core/server.py:161`。
- 证据：`Host: [broken` 返回 500。
- 修复：解析失败返回 403，保留现有主机、来源和写入令牌校验。

### S5 · Medium · CLI 原样显示服务商错误载荷

- 规则：敏感数据最小暴露／不可信终端输出。
- 位置：`crush_cli/app.py:624` 及三个 HTTP 错误分支。
- 证据：服务商 `error.message` 中的合成密钥和聊天文本直接出现在最终错误提示。
- 影响：服务商若回显请求数据，会被复制到终端历史、截图；不可信控制字符也可能进入终端。
- 修复：不读取或展示错误响应体；关闭错误响应，保留 HTTP 状态码及配置、限流等操作建议。此项只覆盖错误路径，不声称所有模型输出已完成终端控制字符审计。

## 已修复的使用问题

1. 4,000 字中文消息使用 JSON Unicode 转义时超过旧 20,000 字节限制，明明没有超出字符上限却被拒绝。实际字节上限改为 64 KiB，4000 字符约束仍由模型校验；同时覆盖补充 Unicode 字符转义的空间需求。
2. 同一模型地址仅增删末尾 `/`，空密钥保存原先会误判为切换服务。现在先规范化地址再比较；换域名依旧不能继承旧密钥。
